# تقرير الإنجاز اليومي — Daily Progress Report

[English](README.md) · [التثبيت على 15 مساعدًا](docs/agent-installation.ar.md) · [الخصوصية](docs/privacy.ar.md) · [ترخيص MIT](LICENSE)

**اسأل: ماذا أنجزنا اليوم؟ لتحصل على تسلسل زمني واضح، وإنجازات حسب المشروع، وأرقام موثوقة، وصورتين إنفوجرافيك: بالإنجليزية والعربية.**

تخيّل أن شغلك موزّع على عدة كراسات. هذه المهارة تعلّم المساعد أن يفتح الكراسات المسموح له بقراءتها، ويبحث عن صفحات اليوم الذي حددته، ثم يحكي ما حدث بالترتيب. لا يخمّن ما بداخل كراسة مغلقة.

## ما معنى «مهارة»؟

هي مجلد بداخله كتيّب تعليمات اسمه `SKILL.md`. وتضم هذه المهارة برنامج Python صغيرًا لقراءة سجلات Codex المحلية. يقرأ المساعد التعليمات ويجمع الأدلة ثم يكتب التقرير. البرنامج يجمع المعلومات، لكنه لا يحكم وحده على نجاح منتج كامل.

هذه مهارة لتلخيص **العمل المسجّل في Codex**. يمكن لمساعد آخر قراءة خطواتها، لكن تثبيتها لا يضيف دعمًا تلقائيًا لسجل محادثات ذلك المساعد ولا يمنحه صلاحية قراءة Codex. يحتاج أدوات Codex مسموحًا بها أو سجلات Codex قابلة للقراءة. عند غياب الأدلة، يجب أن يوضح ذلك.

## ابدأ من هنا: أسهل طريقة للتثبيت

إذا كان مساعدك يستطيع تنزيل الملفات وتثبيت المهارات، انسخ له:

```text
ثبّت مهارة daily-progress-report من
https://github.com/eyoussef-builds/daily-progress-report.
اقرأ دليل التثبيت وافحص المهارة والبرامج المساعدة أولًا.
ثبّت مجلد skills/daily-progress-report كاملًا في مكان المهارات الشخصية
الذي يدعمه هذا المساعد. حافظ على أي نسخة معدّلة موجودة.
أخبرني كيف أشغّلها. لا تقرأ سجل محادثاتي ولا تُنشئ تقريرًا الآن.
```

اقرأ أي طلب إذن للتنزيل أو قراءة الملفات. وللتثبيت اليدوي، استخدم [دليل 15 مساعدًا](docs/agent-installation.ar.md). يتضمن التنزيل دون Git والنسخ على Windows وطريقة قراءة التعليمات للمساعدين غير الداعمين للتثبيت الأصلي.

## أول تقرير، خطوة بخطوة

1. افتح جلسة تستطيع الوصول إلى سجل Codex الذي تريد تلخيصه. الجلسة المحلية تكون عادة أسهل عند استخدام سجلات على جهازك.
2. في Codex اكتب:

   ```text
   استخدم $daily-progress-report. ماذا أنجزنا أمس عبر محادثات Codex
   التي تستطيع قراءتها؟ استخدم منطقتي الزمنية المحلية.
   ```

3. إذا لم يعرف المساعد المنطقة الزمنية، أعطه اسمًا بصيغة IANA مثل `UTC` أو `Europe/London`. ويمكنك تحديد تاريخ صريح. تقرير «اليوم» يقف عند وقت جمع البيانات الموضّح.
4. دعه يفحص المحادثات المتعلقة باليوم، ومنها المحادثات القديمة التي استُكملت فيه والأرشيف المتاح. لا تُضاف الأجهزة الأخرى إلا إذا أمكن قراءة سجلها فعلًا بأدوات متاحة أو نسخة مصدّرة سمحت باستخدامها.
5. اقرأ التسلسل الزمني والإنجازات. افتح روابط المحادثات أو النتائج المهمة إذا أردت مراجعة الادعاء.
6. راجع الأرقام وملاحظة التغطية. «لم نجد نشاطًا مسجّلًا» لا تعني أنك لم تعمل؛ تعني أن السجلات المتاحة لم تثبت نشاطًا.
7. في النهاية تحصل على **صورتين منفصلتين مولّدتين**: الإنجليزية أولًا ثم العربية. تحملان نفس الحقائق والأرقام وتعرضان المخرجات المنجزة. الأعمال غير المكتملة تظل في التقرير المكتوب فقط.

يمكنك أيضًا قول «تقرير إنجاز اليوم» أو «ملخّص اليوم» أو «ماذا أنجزنا أمس؟». اذكر اسم المهارة صراحة إذا لم تُختر تلقائيًا. يشرح دليل التثبيت طريقة الاستدعاء لكل مساعد.

## ماذا ستحصل عليه؟

| الجزء | ماذا يوضّح؟ |
| --- | --- |
| التاريخ والتغطية | اليوم والمنطقة الزمنية ووقت التوقف والمصادر التي قُرئت. |
| التسلسل الزمني | أهم المحطات المسجّلة بترتيب الوقت. |
| إنجازات كل مشروع | ما بُحث أو صُمم أو كُتب أو عُدّل أو بُني أو اختُبر أو نُشر. |
| ما لم يكتمل، نصيًا | الأعمال المهمة غير المنتهية والعوائق منفصلة عن النتائج المكتملة. |
| اليوم بالأرقام | أعداد المشاريع والمحادثات والرسائل الظاهرة والتوكن المسجّل إذا توفرت. |
| إنفوجرافيك إنجليزي | ملخّص مصوّر للإنجازات وشريط أرقام واضح في الأسفل. |
| إنفوجرافيك عربي | نفس الملخص بعربية مقروءة من اليمين لليسار وأرقام `0–9`. |

يُظهر التصميم شخصًا واحدًا يوجّه أنواع عمل مختلفة عبر مركز ذكاء اصطناعي: بحث أو كتابة أو تصميم أو برمجة أو مونتاج أو غيرها مما تثبته السجلات. يعرض المخرجات ومراحل التعديل، لا مجرد أسماء مهام. يتغيّر عدد المسارات حسب اليوم؛ أربع محادثات عن نشاط واحد تظل مشروعًا واحدًا.

## مثال خيالي للتوضيح

لنفترض أنك عملت على تطبيق وجبات ونشرة بريدية، وكلاهما خيالي. أنهيت مخطط التطبيق في 09:10، وأصلحت قائمة المشتريات في 11:30، وجهزت مسودة النشرة في 15:00. يمكن للتقرير عرض **مشروعين** وهذه النتائج إذا أثبتتها السجلات. النشرة المجدولة للغد تُسمّى مجدولة، وليست مُرسلة بالفعل.

هذه أمثلة تعليمية مخترعة، وليست من عمل صاحب المهارة. المستودع العام لا يحتوي تقارير حقيقية أو صور شاشة أو محادثات أو أرقامًا شخصية.

## افهم الأرقام ببساطة

- **المشروع:** المنتج أو النشاط أو العمل المترابط نفسه. قد تتبعه عدة محادثات ومجلدات.
- **الرسائل الظاهرة:** رسائل المستخدم والمساعد بعد حذف التكرار، وتشمل تحديثات التقدم. لا تُحسب استدعاءات الأدوات أو التعليمات الداخلية أو تفكير النموذج، ويُوضّح وجود الرسائل الآلية.
- **التوكن المسجّل:** أجزاء صغيرة من النص يعالجها النموذج، تُحسب من سجلات استخدام كل استجابة داخل اليوم إذا توفرت. إعادة معالجة السياق المخزّن مؤقتًا قد تجعل الرقم كبيرًا؛ ليس عدد كلمات جديدة ولا فاتورة.
- الإدخال المخزّن مؤقتًا وتوكن التفكير أجزاء من الإجماليات، وليسا أرقامًا إضافية تُجمع مرة أخرى. الأرقام الناقصة أو ذات التغطية الجزئية تُوضّح ولا تُخمن.

لا تحوّل المهارة عدد الرسائل إلى ساعات عمل أو ساعات موفّرة أو دخل أو تكلفة أو درجة إنتاجية. تداخل المحادثات لا يثبت أنك عملت باستمرار على كل المسارات في نفس اللحظة.

## ماذا تحتاج؟

عند استخدام أدوات المحادثات، يحتاج المساعد صلاحية عرض المحادثات وقراءتها. للسجلات المحلية تحتاج Python 3.9 أو أحدث مع بيانات المناطق الزمنية، وإذن قراءة مجلد Codex المحدد، وأداة `zstd` إذا كانت السجلات مضغوطة. البرنامج يستخدم مكتبة Python القياسية ولا يحتاج مفتاح API. بعض الأنظمة تحتاج تثبيت بيانات المناطق الزمنية منفصلة.

الصور تحتاج أداة توليد صور فعلية لدى المساعد. المستودع لا يوفّر خدمة توليد ولا يشتري استخدام API تلقائيًا. عند غيابها، يقدّم المساعد التقرير النصي ويشرح أي صور تعذّر إنتاجها. الأهداف الدائمة والجدولة وربط الأجهزة ليست شروطًا لعمل التقرير.

## اختياري: تشغيل برنامج جمع الأدلة يدويًا

من داخل مجلد المستودع الذي نزّلته، غيّر التاريخ والمنطقة الزمنية في المثال:

```sh
python3 -B skills/daily-progress-report/scripts/collect_activity.py --date 2025-01-15 --timezone UTC
```

على Windows استخدم `py -3` بدل `python3` إذا كان مشغّل Python لديك. يقرأ المصدر المحدد في `CODEX_HOME`، وإلا `~/.codex`. استخدم `--codex-root` فقط لمجلد آخر لسجل Codex سمحت بقراءته، و`--help` لمعرفة الخيارات.

يحفظ الناتج افتراضيًا في مجلد مؤقت جديد بصلاحيات خاصة. يخبر حقل `index` المساعد بمكان الأدلة. تحتوي على رسائل ومسارات خاصة، فلا ترفعها ولا تضفها إلى Git. الوضع العادي يختار الملفات بحسب تحديث الفهرس أو الملف ثم يفحص أوقات الأحداث نفسها. يقرأ `--full-scan` كل السجلات المحتفظ بها عندما تكون الأوقات القديمة قد أخفت نشاطًا؛ وقد يستغرق الأرشيف الكبير وقتًا أطول. كلا الوضعين يوضح القيود.

لتشغيل اختبارات بأمثلة مصطنعة دون قراءة سجلك:

```sh
python3 -B -m unittest discover -s skills/daily-progress-report/scripts -p 'test_*.py' -v
```

تستخدم الاختبارات محادثات ورسائل ومعرّفات مخترعة. نجاحها يفحص البرنامج، وليس دقة أي تقرير يومي عشوائي.

## الخصوصية والتخصيص والحدود

يقرأ البرنامج السجل دون تعديله، ولا يحتوي كودًا لرفعه عبر الشبكة. لكن نموذج المساعد وخدمة الصور يعالجان المعلومات المرسلة إليهما بحسب إعداداتهما. اقرأ [دليل الخصوصية](docs/privacy.ar.md). إخفاء أنماط المفاتيح الواضحة إجراء احترازي، وليس ضمانًا لإخفاء الهوية.

يمكن حفظ تفضيلات خاصة مثل المنطقة الزمنية أو اللغة داخل `references/local-profile.md` في نسختك المثبّتة. أبقه خارج Git. احفظ تعديلاتك قبل التحديث. للحذف، أزل مجلد `daily-progress-report` المثبّت فقط أو استخدم أداة الإزالة الخاصة بمساعدك.
